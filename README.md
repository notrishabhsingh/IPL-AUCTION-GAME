# IPL Auction Simulator

A full-stack IPL auction simulation platform that recreates the IPL player auction experience with realistic bidding mechanics, ₹120 Cr purse constraints, squad validation rules, and AI-powered team rankings.

🌐 Live Demo: https://ipl-auction-game-wcs6.onrender.com/

## Key Features

- Realistic IPL-style player auctions
- ₹120 Crore purse management
- Maximum 25-player squad limit
- Minimum 15-player squad requirement
- Maximum 8 overseas players
- AI-powered squad evaluation
- Team rankings and leaderboards
- Interactive auction dashboard
- REST API architecture

## Tech Stack

Frontend: React.js

Backend: Node.js, Express.js

Deployment: Render

AI Integration: Team Evaluation & Ranking System
